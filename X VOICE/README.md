# Golden King - X Voice: מסכת לדים שמגיבה לקול

מסכה עם שתי רצועות לדים שיוצרות X. הלדים מגיבים לעוצמת הקול ולגובה הקול
(המיקרופון המובנה בלוח), ונקישה כפולה על הלוח עוברת בין ארבעה מצבים.

## רכיבים

| רכיב | דגם | הערה |
|---|---|---|
| מיקרו-בקר + מיקרופון + חיישן תנועה | Seeed XIAO nRF52840 **Sense** | מיקרופון PDM ו-IMU (LSM6DS3TR-C) מובנים |
| לדים | 2 רצועות WS2812B 2.7mm, 160/m | רצועה 1: 59 לדים, רצועה 2: 61 לדים. כל רצועה = אלכסון אחד של ה-X |
| ניתוק רצועות | 2 × AO3400A (N-channel, logic level) | בצד ה-GND של כל רצועה, כדי לנתק את זרם ההמתנה בשינה |
| סוללות | 2 × LiPo 400mAh 3.7V | |
| הגנת קו דאטה | נגד 210-470Ω טורי | צמוד לפיקסל הראשון |
| decoupling | קבל 100-220µF | בין V+ ל-GND של כל רצועה, בצד הרצועה של ה-MOSFET |

## חיווט

```
XIAO              רצועה 1 (59 לדים)        רצועה 2 (61 לדים)
D10 --[R]-->  DIN                  D4  --[R]-->  DIN
D7  -------->  gate של MOSFET 1    D5  -------->  gate של MOSFET 2
BAT+  ------>  V+ (שתי הרצועות, ישירות מהסוללה)
GND/BAT- --->  S של שני ה-MOSFETs;  D של כל MOSFET --> GND של הרצועה שלו
```

- ה-GND של כל רצועה עובר **רק** דרך ה-MOSFET שלה. חוט GND ישיר יעקוף את הניתוק.
- אין נגד pull-down על ה-gates (אופציונלי). ה-gate צף רק לרגע בהדלקה ובזמן צריבה.
- הקוד בודק בכל הדלקה שפין ה-gate לא מקוצר לאדמה (חיווט הפוך של רגלי ה-MOSFET),
  ואם כן הוא לא דוחף לתוכו מתח ומדפיס אזהרה ב-Serial.

## מצבים (נקישה כפולה על הלוח מחליפה)

| מצב | מה קורה |
|---|---|
| **מצב X** | האור יוצא ממרכז ה-X ומתפשט לאורך הזרועות. הבהירות לפי עוצמת הקול, ההתפשטות גדלה רק בקול חזק, הצבע לפי גובה הקול |
| **מצב מסיבה** | קשת שזורמת במהירות קבועה. רעש פרלין מעצב את הבהירות: עוצמת הקול = עומק הרעש, גובה הקול = גודל הכתמים |
| **מרוץ לדים** | 4 קבוצות של ~5 לדים רצות על מסלול אחד (רצועה 1 קדימה, רצועה 2 אחורה), רצועה 2 בהפרש מופע של 15 לדים. מהירות לפי עוצמת הקול, צבע לפי גובה הקול |
| **X מתכנס** | בזמן דיבור יוצאים שביטים (חצי גאוסיאן) מארבעת קצוות ה-X ונעלמים במרכז. צבע: אדום בקול רגיל, כתום בנמוך, סגול בגבוה |

**רחבת סאונד** (נקישה מרובעת, 4 נקישות): מעלה את טווח העוצמה מ-30-60 ל-50-75
(`FLOOR_NOISE_FLOOR_DB`/`FLOOR_LOUD_DB`) כדי שמוזיקה חזקה לא תחזיק את המסכה ברוויה.
הבהוב ירוק = נדלק, אדום = כבה. אותו דבר מה-Serial: `V`. נקישה כפולה מגיבה עכשיו
~0.5 שניות אחרי הנקישה השנייה (מחכה לראות אם יש עוד נקישות).

בהירות כללית לכל המצבים: `GLOBAL_LEVEL` (כרגע 0.5 = חצי מהבהירות הנתפסת).

## טריגר: נקישה כפולה

חיישן התאוצה נקרא דרך ה-FIFO שלו ב-833Hz (בפועל ~905Hz), מסונן מעל 30Hz,
וזוג נקישות במרווח 120-500ms, אחת לפחות 4.5g והשנייה לפחות 2g, מחליף מצב.
על ההקלטות: כל הנקישות הכפולות נתפסו (גם תוך כדי ריקוד), 0 טריגרי שווא
בריקוד/הליכה/לבישה/הנחה. (הטריגר הקודם, קליק כפול של הלשון, נשאר בקוד
כבוי - `USE_CLICK_TRIGGER 0` - כי במסיבה אמיתית הוא נדלק מהרעש.)

## שינה

5 דקות בלי תנועה ובלי דיבור: המיקרופון, הג'ירו והלדים כבים, וה-MOSFETs
מנתקים את הרצועות לגמרי. תאוצה (הרמה / ניעור) מעירה.

## בנייה וצריבה (arduino-cli)

- Board package: **Seeed nRF52 mbed-enabled Boards** (`Seeeduino:mbed`), צריך את
  ה-URL `https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json`
- ספריות: `Adafruit NeoPixel`, `Seeed Arduino LSM6DS3`

```bash
arduino-cli compile --fqbn Seeeduino:mbed:xiaonRF52840Sense "X VOICE/led_mask_audio_reactive"
arduino-cli upload --fqbn Seeeduino:mbed:xiaonRF52840Sense -p COM3 "X VOICE/led_mask_audio_reactive"
```

## כלי פיתוח (Python: `pip install pyserial matplotlib numpy`)

| קובץ | מה עושה |
|---|---|
| `serial_plotter.py` | גרף חי של עוצמה, בהירות וגובה קול. `--calibrate` = כיול מודרך (שקט/דיבור/נמוך/גבוה/צעקה) |
| `stream_session.py` | מקליט סשן חי: אודיו מהמיקרופון של הלוח, תאוצה ב-833Hz, טריגרים. `--taps` = סשן מודרך לטריגר הנקישה |
| `capture_trigger.py` | הקלטות קצרות (2.5 שניות) מהמיקרופון של הלוח |
| `led_finder.py` | מדליק לד אחד בכל פעם, למיפוי המספרים על המסכה |
| `center_tuner.py` | מזיז את מרכז ה-X של כל רצועה בחצאי לדים, חי, עם שביטים רצים (X מתכנס) לבדיקה |

מרכז ה-X: רצועה 1 לד 29, רצועה 2 לד 31 (`STRIP1_CENTER`/`STRIP2_CENTER`, אפשר x.5).

פקודות Serial בלוח: `S`/`X` הזרמה, `R` הקלטה, `L<strip>,<led>` מאתר לדים,
`K<strip>,<center>` מרכז חי, `O<n>` קפיצה למצב, `V` רחבת סאונד, `W` שביטי דמו,
`C` תבנית בדיקת מיפוי (אדום = מרכז, כחול = קצוות), `P` בדיקת קצר בפיני ה-gate,
`D` דאמפ רגיסטרים של ה-IMU.
