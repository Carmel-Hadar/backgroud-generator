# מסכת פנים עם לדים ריאקטיביים לקול

## רכיבים (BOM)

| רכיב | דגם | הערה |
|---|---|---|
| מיקרו-בקר | Seeed XIAO ESP32-S3 | טעינת ליפו מובנית, RMT ל-WS2812B, I2S חומרתי למיקרופון |
| מיקרופון | INMP441 (I2S דיגיטלי) | מוצמד לחזה, מחובר ב-4 חוטים (VDD/GND/WS/SD/SCK) |
| לדים | WS2812B, 0807 SMD, 2.7 מ"מ, 160/מ', ~1.5מ' (240 פיקסלים), 5V | שבב WS2812B אמיתי, פרוטוקול סטנדרטי |
| סוללה | LiPo 400mAh 3.7V, JST-PH 2.0 | מחובר ישירות ל-XIAO; ניתן להגדיל קיבולת בלי לשנות קוד |
| הגנת קו דאטה | נגד 330-470Ω (SMD 0805) | טורי, צמוד לפין הראשון של הרצועה |
| decoupling | קבל 100-220µF | בין V+ ל-GND, צמוד לפין הראשון של הרצועה |

## חיווט

```
XIAO ESP32-S3          INMP441
  3V3          ------>  VDD
  GND          ------>  GND, L/R
  D1 (GPIO2)   ------>  WS
  D2 (GPIO3)   ------>  SD
  D3 (GPIO4)   ------>  SCK

XIAO ESP32-S3          LED strip (WS2812B, 5V)
  D0 (GPIO1)   --[R 330-470Ω]-->  DIN (פיקסל ראשון)
  BAT+ (מסוללה)  -------------->  V+   (ישיר, בלי בוסט קונברטר)
  GND            -------------->  GND
                 [קבל 100-220µF בין V+ ל-GND, צמוד לפיקסל הראשון]
```

**חשוב**: הרצועה מחוברת ישירות למתח הסוללה הגולמי (3.7-4.2V), לא ל-5V רגולציה
נפרד. WS2812B עובד טוב בטווח הזה, וזה גם משפר את שולי הרמה הלוגית מול
היציאה של 3.3V מה-ESP32.

## תקציב הספק וסוללה

- 240 פיקסלים, ~5.76W/מ' × 1.5מ' ≈ 1.8A בעומס מקסימלי תיאורטי (לבן מלא, בהירות מלאה).
- `FastLED.setMaxPowerInVoltsAndMilliamps()` בקוד מגביל את זה אוטומטית (ברירת
  מחדל: 700mA - להתאים לפי קיבולת/C-rating הסוללה שתבחר בפועל).
- הגבלת התוכנה העיקרית היא עקומת המיפוי (ראה למטה): גם בעומס קול מקסימלי,
  העוצמה לא עוברת את `MAX_LEVEL` (ברירת מחדל 0.80 = 80%).

## כיול המיקרופון

1. פתח Serial Monitor ב-115200 baud.
2. הסר את ה-`//` מהשורה `// Serial.println(db);` בפונקציה `rmsToLevel()` (או השאר
   כפי שהיא ופשוט עקוב אחרי ההתנהגות הויזואלית - זה עניין של העדפה).
3. בשקט מוחלט - רשום את ערך ה-dB. קבע את `NOISE_FLOOR_DB` כמה יחידות מעליו
   (כדי שרעש רקע לא ידליק את המסכה).
4. דיבור רגיל - זה אמור למפות לעוצמה נמוכה-בינונית עם העקומה כברירת מחדל.
5. הכי חזק שמצפים שיקרה בפועל (צעקה/שירה) - קבע את `LOUD_DB` לערך הזה. זו
   הנקודה שמגיעה ל-`MAX_LEVEL` (80% כברירת מחדל).

פרמטרים נוספים לכוונון בקובץ:
- `CURVE_EXPONENT` (ברירת מחדל 2.5) - ככל שגבוה יותר, עוצמות בינוניות "נדחסות"
  נמוך יותר, ורק ווליום ממש גבוה מטפס מהר לכיוון התקרה.
- `MAX_LEVEL` (ברירת מחדל 0.80) - תקרת העוצמה המוחלטת, בלי קשר לווליום.
- `ATTACK_ALPHA` / `DECAY_ALPHA` - קצב עליה/ירידה של האפקט (עליה מהירה, ירידה
  איטית יותר, לתחושת "פעימה" טבעית).

## החלפת האפקט הויזואלי

הקוד כברירת מחדל עושה סבב צבעים איטי (hue rotation) כאשר הבהירות עוקבת אחרי
עוצמת הדיבור (`smoothedLevel`). כדי לממש אפקט אחר - יש לערוך רק את
`renderEffect()`; שאר הקוד (קריאת מיקרופון, RMS, עקומת המיפוי, החלקה) לא צריך
להשתנות.
